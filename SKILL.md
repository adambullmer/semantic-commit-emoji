# semantic-commit-emoji

This skill provides guidelines and style rules for authoring commit messages using the `semantic-commit-emoji` convention.
This convention builds upon the original Conventional Commits specification by automatically prefixing a corresponding emoji based on the semantic commit type.

Please refer to the following resources for detailed instructions:

- [Conventional Commits Spec](./skills/conventional-commits.md): For understanding the base specification and structure of conventional commits.
- [semantic-commit-emoji Style Rules](./skills/semantic-commit-emoji-style.md): For the specific mapping of types to emojis and overall style requirements for this project.
- [Staging and Splitting Commits](./skills/staging-and-splitting.md): For instructions on how to group changes and split up work into atomic commits.
